ALGORITMA PENYELESAIAN SPL 3 VARIABEL
Metode: Eliminasi Gauss dengan Partial Pivoting + Substitusi Mundur
Nama: Clarita Vivana Mali | NIM: 202511420093

BENTUK MASALAH
  a11 x + a12 y + a13 z = b1
  a21 x + a22 y + a23 z = b2
  a31 x + a32 y + a33 z = b3
  Ditulis A.x = b, dengan A berukuran 3x3 dan b vektor 3x1.

INPUT  : matriks koefisien A (3x3), vektor konstanta b (3)
OUTPUT : vektor solusi x = (x, y, z), atau pesan bahwa solusi tunggal tidak ada

LANGKAH
 1. Mulai.
 2. Baca matriks A dan vektor b.
 3. Bentuk matriks augmented M = [A | b] berukuran 3x4.
 4. Untuk k = 1 sampai 2 (kolom pivot):
    4.1 Cari baris p (p >= k) yang |M[p,k]| paling besar.
    4.2 Jika |M[p,k]| mendekati nol (< 1e-12), tampilkan "matriks singular" lalu Selesai.
    4.3 Jika p tidak sama dengan k, tukar baris p dengan baris k.
    4.4 Untuk i = k+1 sampai 3:
        a. faktor = M[i,k] / M[k,k]
        b. Baris_i = Baris_i - faktor * Baris_k
 5. Jika |M[3,3]| mendekati nol, tampilkan "matriks singular" lalu Selesai.
 6. Substitusi mundur:
    z = M[3,4] / M[3,3]
    y = (M[2,4] - M[2,3]*z) / M[2,2]
    x = (M[1,4] - M[1,2]*y - M[1,3]*z) / M[1,1]
 7. Verifikasi: hitung residual r = A.x - b; nilainya harus mendekati nol.
 8. Tampilkan x, y, z dan residual.
 9. Selesai.

PSEUDOCODE
  BACA A, b
  M <- gabung(A, b)
  UNTUK k <- 1 SAMPAI n-1
      p <- indeks |M[k..n, k]| terbesar
      JIKA |M[p,k]| < eps MAKA cetak "singular"; STOP
      TUKAR baris k dan p
      UNTUK i <- k+1 SAMPAI n
          f <- M[i,k] / M[k,k]
          Baris_i <- Baris_i - f * Baris_k
  JIKA |M[n,n]| < eps MAKA cetak "singular"; STOP
  UNTUK i <- n TURUN SAMPAI 1
      x[i] <- (M[i,n+1] - jumlah(M[i,j]*x[j], j=i+1..n)) / M[i,i]
  CETAK x

CONTOH
  2x + y - z = 8 ; -3x - y + 2z = -11 ; -2x + y + 2z = -3
  Hasil: x = 2, y = 3, z = -1

ALASAN PARTIAL PIVOTING
  Memilih pivot terbesar mencegah pembagian dengan nol dan memperkecil galat pembulatan.
